# 模型标注与审计协议 v1

2026-09-13：用户选择 Grok 标注、另一模型独立审计、Codex 分层抽查，不要求人类核验。这是当前路线；旧人工试用表原样保留，未填写不再阻塞推进。标签属于 **MODEL_AUDITED_REFERENCE**，不属于人工 gold。协议在本轮模型调用之前确定。

## 任务与抽样

每项是“评论片段 + 一个方面”，判断 positive / negative / neutral / not_about_aspect；混合、反讽、截断导致含义不清等用 uncertain 标记，不硬凑答案。七方面为位置、清洁、早餐、服务、噪声、房间和性价比。房间方面指空间、设施、床铺等，不因文字出现 room 就把清洁情绪同时当成房间情绪。正负栏目不是答案。

从原始 515,738 行 CSV 完整扫描，用 seed=42 的分层蓄水池抽样。先取每条正/负评论前 800 字符，过滤占位文字，再执行现有方面关键词筛选。六城市 × 七方面 × 两栏目各抽 2 项，共 168 个命中项；每个城市/方面另抽 1 个未命中片段，共 42 个漏检诊断项，目标 210。记录各层候选量、实际样本量和覆盖酒店数，不伪称每家酒店都有样本。原始 CSV SHA256 必须符合配置。

这是覆盖不同情形的诊断集，**不是按总体比例抽取的准确率样本**。同一评论可对应不同方面；统计单位是评论方面对，不是独立住客人数。800 字符截断可能丢失后文。本轮用于发现错误和固定规则；看到结果后据此修改规则，就必须另外冻结新的测试集，不能把本轮再次用作无偏最终测验。

## 独立标注与复核

1. Cursor CLI / `cursor-grok-4.6-medium` 初标全部项。
2. Cursor CLI / `claude-sonnet-5-medium` 独立重标全部项，只看到相同任务定义、匿名 ID、方面与片段；看不到 Grok 输出、原始栏目、分数、酒店身份、城市或关键词命中信息。两者属于不同模型系列，但仍可能存在共同偏差。
3. 本地程序校验完整 ID 集合、不重复、标签枚举、布尔不确定标记，以及相关标签所引证据确实是输入片段的连续子串。格式失败最多两次尝试，成功批次按输入/提示词/模型哈希断点复用。校验失败不算完成。
4. 两模型同标签且均不确定标记为假，才进入暂接纳池。其余全部进入审计队列；暂接纳池再按方面固定随机抽至多 2 项/方面。Codex 读片段与两方判定，逐项记录通过/异议/不确定及简短依据。
5. **用户追加授权 Codex 最终裁决**（在本轮真实模型调用前更新）：对全部分歧/不确定项，Codex 依据片段与固定规则决定最终标签并留理由和原文证据；证据含糊时仍保留 unresolved。一致项抽查发现错误也由 Codex 更正或撤回。不以多数票代替文本依据，不改写两模型原始答案。未抽查一致项标为双模型一致，不能标第三方逐条审计。最终标签来自模型审计，不是人类 gold。

## 记录、指标与发布

私有目录 `outputs/autonomous/private/model_annotation_rounds/` 保留采样文本、两模型答案、短理由、调用与错误记录、哈希、最终标签、抽查记录。编码 agent 只读 schema 和合成数据；用户授权的标注角色才接收必要片段。评论中的指令视为数据，标注角色禁止执行工具或访问项目。GitHub 只提交代码、协议与无原文/无酒店标识的聚合报告。

报告两模型一致数/比例、Cohen κ、各方面和城市的分歧、未命中项判断、暂接纳与最终保留数量、抽查覆盖与撤回数量。小样本层级比例只描述本轮，不用作酒店总体准确率。现有 84.61% 弱标签一致率保持原来的含义，不能换名为本轮成果。不得把 LLM 自信度当校准概率。

当前路线无需人类逐条核验，也不因此宣称真实标签正确、酒店收益提升或论文结论已经成立。模型标签能支持自动诊断与方法对比，不能单独证明建议能在真实酒店奏效。后续研究方案见 [HANDOFF.md](../HANDOFF.md)。

## 本机命令与复现边界

研究 Python 为 `.venv-fyp/bin/python`。`scripts/model_annotation.py prepare` 冻结样本，`run --role grok --model cursor-grok-4.6-medium` 与 `run --role reviewer --model claude-sonnet-5-medium` 分别生成盲标批次，`summarize` 生成配对结果和抽查队列；每条命令的 `--round` 指向同一私有轮次。Codex 完成私有 `codex_audit.json` 后，再运行 `scripts/finalize_model_annotation.py --round ... --audit ... --report outputs/autonomous/model_annotation/final_20260913.json`。具体参数见 `--help`。

成功批次可断点复用；统计和终审产物拒绝覆盖，应保留已有轮次并为新实验建新目录。样本抽取与本地统计可确定性复现；远端模型版本和生成存在变化，不能保证重调逐字一致，因此保存模型请求 ID、时间、提示词哈希、原始回复及全部尝试日志。CLI 返回的模型字段仅记录请求选择，不伪造无法从响应核验的底层服务版本。含文本与裁决的材料不推 GitHub；克隆代码后需恢复本机数据/记录才能完整复现。
