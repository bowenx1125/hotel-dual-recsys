## 0. 结论先行

**P4 做完，结论是负的，但这个负结论比一个正结论值钱得多：**

1. **P4 只能做「直接法」，不能做 IPS/SNIPS** —— 项目自己的硬约束（R1 P2）禁止。
2. **在决策相关的「前瞻」奖励下，评估协议没有区分力**：真实 gap 0.0260 vs 置换安慰剂 gap 0.0216，**比值仅 1.20**。

4. **折分离后，季度评分变化基本不可预测**（R²≈0.001）；池化状态下看起来的预测力 **98% 来自同一批评论的重叠**。
5. **唯一有真信号的目标是「酒店横截面评分水平」**（折A 方面画像 → 折B 评分水平，R²=0.449、r=0.670）。这是 P3 唯一站得住的优化目标，但它是关联性的、不是因果的。

## 1. 为什么不是 IPS/SNIPS

`outputs/autonomous/wave6/policy.json` 白纸黑字 `no_ips_snips: true`，且 `wave9/ADVERSARIAL_REVIEW.md` 的 R1 P2 规则写的是
**「No logged policy: Do not wrap offline evaluation as IPS/SNIPS.」**

这不是保守，是事实：IPS/SNIPS 需要**日志策略**（行为策略）给出的动作倾向性概率，本项目没有任何线上曝光/点击/采纳日志，没有可除的倾向性。硬套只会造出一个假数字。

因此 P4 用的是**直接法（Direct Method / 结果回归）+ 交叉拟合**，不需要倾向性得分：

```
r_it = Σ_a γ_a · x_it,a + 季度哑变量 + 酒店固定效应 + ε_it
```

- `x_it,a`：方面 a 的情感季度变化，**只用检测折（A）**
- `r_it`：**另一折（B）** 的季度评分变化 → 与状态无共用评论，切断机械耦合
- 策略价值：`V(π) − V(ref) = δ · Σ_a (p_a^π − p_a^ref) · γ_a`，δ = 参考改善幅度（0.1229，即正的情感变化的中位数）

因为所有策略在**同一批状态**上打分，与动作无关的项在对比中全部抵消，所以价值对比只依赖 γ 与其酒店聚类协方差。标准误同时给了**delta 法**和**酒店聚类 bootstrap（200 次）**两个口径，两者不一致时以更保守者为准。

**状态也做了折分离**：现有 Demo 的状态是池化的（`smoothed_net` 含两折评论），直接拿来做策略输入会让结果折的评论泄漏进特征。P4 重新构造了「只含单折」的面板（`src/effect/ope.py::fold_panel`），含分折提及数、分折 `raw_net`、分折可靠性。

## 2. 结果

### 2.1 前瞻规格（决策相关，`x` 在 t，`r` 是 t→t+1）

样本：2646 单元/方向，795–799 家酒店/方向，2016Q1–2017Q1（5 个季度，前后都需完整季度）。

| 方面 | γ（分/单位情感） | se | t |
|---|---|---|---|
| location | −0.0735 | 0.0686 | −1.07 |
| cleanliness | +0.0448 | 0.0476 | +0.94 |
| breakfast | +0.0060 | 0.0471 | +0.13 |
| service | −0.0796 | 0.0572 | −1.39 |
| noise | −0.0588 | 0.0454 | −1.29 |
| room | −0.0244 | 0.0660 | −0.37 |
| value | +0.0003 | 0.0463 | +0.01 |

**七个方面没有一个显著。**

| 策略 | 价值 | se | t |
|---|---|---|---|
| peer_relative（**现行**） | −0.0026 | 0.0027 | −0.95 |
| largest_peer_gap | −0.0026 | 0.0025 | −1.07 |
| random_uniform（**随机**） | −0.0023 | 0.0021 | −1.11 |
| always_service | −0.0098 | 0.0070 | −1.39 |
| oracle_best | +0.0055 | 0.0059 | +0.94 |

**区分力检验（核心）**

| 量 | 值 |
|---|---|
| 分样本 best−worst gap | **+0.0260**（20 次重复的 sd 0.0050） |
| 置换安慰剂 gap（奖励在季度内打乱） | **+0.0216** |
| **比值** | **1.20** |

打乱奖励后，max−min 的「区分力」仍有 0.0216 —— 说明这个 gap **主要是 6 个噪声系数取极值带来的次序统计偏误，不是真实信号**。

### 2.2 同期规格（描述性，`x` 与 `r` 同一区间）

| 方面 | γ | se | t |
|---|---|---|---|
| **service** | **+0.1917** | 0.0599 | **+3.20** \* |
| location | +0.1323 | 0.0671 | +1.97 \* |
| cleanliness | −0.0067 | 0.0546 | −0.12 |
| breakfast / noise / room / value | — | — | 均不显著 |

这与 P2 的 `contemp` 结果（service +0.191, p=7.5e-6）**独立复现，量级一致**。

| 对比 | 差值 | delta 法 t | bootstrap se | bootstrap t |
|---|---|---|---|---|
| **peer_relative − random_uniform** | **+0.0004** | +0.24 | 0.0023 | **+0.17（不显著）** |
| always_service − peer_relative | +0.0175 | +2.45 \* | 0.0112 | **+1.56（不显著）** |
| largest_peer_gap − peer_relative | +0.0013 | +1.24 | 0.0016 | +0.81（不显著） |
| gap-dominant − current-default | +0.0007 | +1.30 | — | — |
| oracle_best − random_uniform | +0.0179 | +2.65 \* | 0.0064 | **+2.80（显著）** |

**三条读法：**
- 现行策略 ≈ 随机（+0.0004，t=0.24）。这不是说策略没用，是说**这套数据下无法证明它比随机强**。
- 「总推 service」看起来好 0.0175 分，但 **bootstrap 下不稳健**（t 从 2.45 掉到 1.56），不能作为 P3 的依据。
- 只有「知道 γ 的 oracle」才稳定超过随机 —— 而 oracle 用的是被评估的同一个 γ，本身就是上界。

## 3. 预测探针：还能不能换个目标？（P4b）

既然因果走不通，退一步问：**预测**需不需要因果？不需要。于是测了三档目标（`src/effect/probe_predictive.py`）：

| 目标 | 折分离 R² | 说明 |
|---|---|---|
| 季度**变化**（方面状态 → 下季评分变化） | **+0.0010** | 折A 特征 → 折B 目标，无共用评论 |
| 同上，但用**池化**状态 | +0.0445 | 特征里含结果折的评论 |
| 酒店**水平**（折A 方面画像 → 折B 评分水平） | **+0.4490** | 1300 家酒店，RMSE 0.457 vs sd 0.617，r=0.670 |

**机械膨胀 = 0.0445 − 0.0010 = +0.0435**，即池化设定下的表观预测力 **98% 来自同一批评论的重叠**。

这是一个可以直接写进论文的阴性对照：**任何用池化数据声称「方面情感能预测未来评分」的结论，量到的都是评论重叠本身。**

## 4. 对 P3 的含义：唯一站得住的目标

| P3 候选目标 | 可评估性 | 结论 |
|---|---|---|
| 调权重 → 提高下季评分（因果） | ✗ | 前瞻规格全不显著，协议无区分力 |
| 调权重 → 更好**预测**下季评分 | ✗ | 折分离后 R²≈0.001，季度变化是噪声 |
| 调权重 → 更好解释**评分水平**差异 | ✓ | R²=0.449，有真信号、可分辩 |
| 调权重 → 增加酒店收益 | ✗ | 无价格/间夜数据，永远做不到 |

**建议 P3 的做法：**

1. **把目标从「变化」改成「水平」。** 用折 A 的方面画像拟合折 B 的评分水平，得到一个**学习出来的方面价值向量**（替代现在手设的 gap/criticism/unreliable 三权重）。这正好能把 `weights_are_design_choices: True` 变成 `False`。
2. **把「方面专属价值」引入排序。** 现行排序只用 gap / criticism / unreliability，**完全没有方面专属的价值系数** —— P2 与 P4 都显示 service 的 γ 显著高于其它方面（+0.19 vs ≈0），这是现行公式结构性缺失的一项。
3. **验收口径写死**：P3 的任何增益必须在**折分离 + 酒店外样本**上超过基线，且必须报告**相对置换安慰剂的倍数**，不能只看 gap 绝对值。
4. **话术必须降级**：这一步能支撑的是「更好地把评分短板归因到方面」，**不是**「改善方面 X 会提升评分/收益」。

## 5. 局限（必须写进论文）

1. **覆盖 53%**：进入评估的单元要求 7 个方面在连续两个季度、在**单一折**上都有提及。折 purity 把数据量减半，代价就落在覆盖率上。
2. 直接法的价值依赖结果模型设定正确；这只是**下界保证**，不是无偏估计。
3. 折分离消除了「同一条评论」的机械耦合，但**不等于随机化** —— 酒店改善哪个方面仍是自选的。
4. 同期规格中 location 的 γ 边际显著（t=1.97），说明**阴性对照并不干净**（客人对位置的评价会随整体满意度波动）。P2 已暴露过一次，此处再次出现。
5. 敏感度为**零结果**（min_mentions 非绑定），真正的旋钮是 `min_reliability`。
