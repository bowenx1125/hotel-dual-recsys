## 一句话结论

> 系统本身完整可用，四轮实证研究拿到了真实的算法侧信号；但「证明这套系统能增加酒店收益」按现有数据做不到——**缺的不是更好的算法，是干预记录和收益数据**。可辩护的推荐逻辑是「对最薄弱、且测量可靠的方面采取行动」，现役的 peer-relative 排序实现的正是这条。

四个不同角度、四套方法、互相独立，全部指向同一结论。

## 论文必须披露的局限

53% 覆盖率、location 阴性对照偏弱（p=0.046 边际显著）、Direct Method 的模型依赖、条件/边缘规格分歧不可判定、方面排序的方向依赖。
