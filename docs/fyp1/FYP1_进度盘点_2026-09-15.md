## 1. 项目在做什么

**研究问题**：酒店经理面对大量住客评论，应该先处理哪件事？

- **输入**：历史住客评论、评论日期、酒店坐标与评分
- **处理**：按关键词识别七个方面（service / room / breakfast / location / cleanliness / value / noise），贝叶斯收缩避免少量评论造成极端判断，与同城地理近邻做差距比较
- **输出**：方面测量、与附近的差距、行动建议，以及在证据不足时**明确弃权**

**数据**：Booking.com 欧洲六城（Paris / London / Barcelona / Milan / Vienna / Amsterdam）评论面板，源面板 1,493 家酒店、515,738 条评论。

**重要边界**：现有数据是**评论和评分**，没有任何管理侧或经营侧字段。这一点决定了后面所有的结论。

## 3. 这四轮做了什么

目标是为「证明能增加酒店收益」补上可信的效应证据链。四轮全部采用**折纯设计**（在折 A 上检测、在互斥折 B 上测结果），因为初版 Wave5 存在自指缺陷——用池化的评论同时充当处理与结果。

### P1/P2 效应估计 → `AMBER_ASSOCIATIONAL`

- **P1** 冻结基线，把 Wave5 的自指缺陷连同 9 个产物哈希一并记录，并写入验收标准：后续必须超过 P2 的折外效应，**禁止降门槛**。
- **P2a** 原面板只有池化评分、无法做折外测量。按 `sha1(review_fingerprint) % 2` 重扫 515,738 行原始 CSV，生成分折因变量（折 A/B = 258,244 / 257,494，与已发布面板 0 条不匹配，池化均分最大偏差 2.3e-14）。
- **P2b** 交叉折双向固定效应 + 酒店聚类稳健 SE。同期·水平 **+0.187**（p=7.5e-27），service 最强 +0.191、breakfast 最弱 +0.060。**同折机械耦合对照是它的 4.5–11 倍**，量化了原来自指偏差有多大。
- **P2c** 匹配 DiD：折外评分臂 k=0 为 **+0.1139**（p=0.0019），k=−2 平行趋势 −0.0219（p=0.55），k=1/k=2 衰减且不显著。

**结论**：方面口碑与其他客人评分**同步**关联稳健（两个独立设计互相印证），但**领先效应是负结果**——「改善方面 X 会提升下季度评分」无证据。仍无价格/间夜/成本字段。

### P4 离线策略评估 → `AMBER_NO_DISCRIMINATION`

项目无日志策略（配置 `no_ips_snips: true`，规则明令禁止包装成 IPS/SNIPS），因此用**直接法（结果回归）+ 交叉拟合**。

- 前瞻规格：七个方面的 γ **全部不显著**（|t| ≤ 1.39）；best−worst gap 0.0260 vs 置换安慰剂 0.0216，**比值仅 1.20** → 该差距主要是 6 个噪声系数取极值的次序统计偏误。
- 现行策略 `peer_relative` 与**随机挑一个方面无法区分**（+0.0004 分，t=0.24）。
- **P4b 预测探针**（这一条决定了后面所有方向）：折分离后季度评分变化**不可预测**（R²≈0.0010）；池化状态 R²=0.0445，其中 **98% 是同一批评论重叠造成的机械膨胀**；而**酒店横截面**（折 A 方面画像 → 折 B 评分水平）**R²=0.4490、r=0.670**（n=1300）。

→ **唯一有信号的目标是横截面水平，不是季度变化，更不是收益。**

### P3 方面价值向量与价值感知排序 → 算法侧达成

按 P4b 的指引，把靶标换成横截面，拟合 `y_i = c + Σ_a v_a·x_{i,a}`：

- **真实性**：折外 CV R² **0.4413 / 0.4601**；打乱标签 placebo R² **−0.0015**，**比值 304**；两个不相交酒店半区估出的向量相关性 **0.982**（40 次重复 100% 为正）。
- **系数（评分点/SD）**：room **+0.2786**(t=15.27)、service **+0.2599**(13.56)、noise +0.0814(5.89)、value ≈0、breakfast −0.0102、cleanliness **−0.0814**(t=−5.34)、location −0.0564（不可行动）。
- **反直觉发现**：cleanliness 的条件系数为**负**。与边缘（单变量）系数 **+0.1801 符号相反**——设计矩阵条件数 3.1、共线性轻微，**不是数值假象**，是信号被 room/service 吸收。无干预数据则不可判定选哪个，已选条件规格并写明理由。
- **与现役策略一致率仅 59.2%** ⇒ **40.8% 的推荐会改变**。
- **决定性复核（Q4）**：四种配置下 `value_aware − peer_relative` = −0.00021 / −0.00483 / +0.00434 / +0.00257 评分点，**全部 |t| ≤ 0.95**，检测阈值约 0.013 → **收益没动**，完全复现 P4 的结论。

**默认关闭**（`use_learned_value_vector: false`），Demo 行为逐字节不变。v 是估计量，带自己的 n/R²/placebo，不得混进 `conf/` 冒充设计常量。

### P5-A 揭示性干预事件研究 → 改进有回报，但方面排序不可判定

既然没有干预日志，用**评论里持续性的方面情感跃迁**作为干预的揭示性代理（检测折识别、互斥折测结果，A→B 与 B→A 都跑）。

| 主张 | A→B | B→A | 判定 |
|---|---|---|---|
| 改进是否有回报 | +0.0656 (t=3.46)，前趋势 t=−0.94 | +0.0652 (t=3.43)，前趋势 t=−2.11 | **跨折复现** |
| 哪个方面回报最高 | 比值 1.029，p=0.402 | 比值 1.863，p=0.008 | **方向依赖** |
| 点名的方面 | cleanliness | value | 不一致 |

- A→B 的差距与随机置换安慰剂**等大**（0.115 vs 0.112）→ 纯属次序统计量膨胀；
- B→A 虽过安慰剂，但**该方向前趋势 t=−2.11 未通过** → 那部分是均值回归；
- τ 敏感性：合并效应稳健（t=2.57–4.45），但**最佳方面来回翻转**（service→cleanliness→service→value）。**效应稳、排序不稳。**
- P3 的横截面向量**不能迁移**到这个靶标（z=0.753, p=0.227）——它估的是水平，这里是变化。

**样本量要求**（把"缺数据"变成具体数字）：σ=0.909 评分点，当前 **MDE = 0.171 评分点**。

| 要检出的效应（评分点） | 每方面需要的记录数 | 6 个可行动方面合计 |
|---|---|---|
| 0.05 | 5,190 | 31,140 |
| 0.10 | 1,298 | 7,788 |
| 0.20 | 325 | 1,950 ✅ 现在就能 |
| 0.50 | 52 | 312 ✅ 现在就能 |

## 4. 最关键的判断：收益证明为什么拿不到

原始目标要求打通这条链：

```
排序策略 → 推荐动作 → 经理是否采纳？ → 酒店整改 → 评分回升 → 需求上升 → 收益上升
                      ↑ 观测不到                ↑ 观测不到       ↑ 观测不到
```

**三个问号，数据里一个都观测不到。** 逐项核对过：

- 原始 Booking 评论只有 17 列（地址、评分、日期、正负面文本、标签、经纬度等），**没有任何管理侧或经营侧字段**；
- 曾尝试用爬取价格补：`hotels_all.csv` 321 行有价（EUR 中位 129），但**全是比利时城市**，面板城市是 Paris/London/Barcelona/Milan/Vienna/Amsterdam → **交集为空集**。ID 映射本身是通的（1493/1493 匹配），**缺的是那张表**。ADR 129 只能当**量级锚点**，不能连接、不参与任何估计。

**四个不同角度、四套方法、互相独立，全部指向同一结论**——这就是它不是"某一次没做好"而是可识别性边界的原因。

## 5. 现在能对外说什么

✅ **可以说**（有跨折复现 + 前趋势 + 安慰剂支撑）：

1. 方面口碑与其他客人评分存在稳健的**同步**关联（两个独立设计互相印证）。
2. 酒店横截面上，方面画像对评分水平有强预测力（R²≈0.45，placebo 比值 304），且学到的价值向量在独立酒店半区上稳定相关（0.982）。
3. 现役启发式排序有 **40.8% 的推荐**在"哪个方面更值钱"上是可商榷的。
4. 持续性的方面改进之后，评分会回升约 **+0.065 点**（t≈3.4，双折复现）。
5. 因此可辩护的推荐逻辑是：**对最薄弱、且测量可靠的方面采取行动**——现役的 peer-relative 排序实现的正是这条。

❌ **不能说**：

1. "本系统能提升酒店收益"——采纳与收益两个环节均无观测。
2. "针对 X 方面投入，因为它回报最高"——方向依赖，且唯一显著的方向前趋势未通过。
3. 任何把 ADR 129 参与计算后得到的收益数字——样本国家不同、未连接、弹性是外部假设。
4. 任何 IPS/SNIPS 形式的策略评估——项目规则禁止，且本设计不需要。

## 6. 还差什么

### A. 被外部数据卡住的（需要去谈，不是写代码能解决的）

| 需求 | 优先级 | 最小字段集 | 有了能证什么 |
|---|---|---|---|
| 干预 / 采纳日志 | **决定性** | `hotel_id, action_aspect, action_date, adopted` | 方面间的回报差异（需 1,950–31,140 条，见 §3 表） |
| 收益序列 | 高 | `hotel_id, period, ADR, occupancy`（或 RevPAR） | 把评分点换成钱，不靠外部弹性假设 |
| 面板城市价格 | 中 | 同上价格部分 | 至少能做量级折算（当前比利时样本用不上） |

### B. 可以继续做的（不需要外部数据）

1. **论文**（最大缺口，HANDOFF §5.4 明确列了）——用真实结果更新草稿，**保留四轮的零结果**。
2. **公平比较与消融**（§5.3）——在相同酒店/时期/信息上分别移除附近参照、可操作性、可靠性、弃权。
3. **固定最终评测方案**（§5.2）——新测量测试集与开发集按酒店隔离，报 Macro-F1、混淆表、保留率、未决分布。
4. **系统文献查重**（§5.4）——组件本身是已有方法，不能写"首创"。

### C. 只能负责人填的

学校格式模板、截止日期、导师反馈。HANDOFF §5 末尾写明了这些不能由 agent 猜测。

**论文必须披露的局限**：53% 覆盖率、location 阴性对照偏弱（p=0.046 边际显著）、Direct Method 的模型依赖、条件/边缘规格分歧不可判定、方面排序的方向依赖。

## 附：术语小词典

| 术语 | 含义 |
|---|---|
| **折纯（fold-pure）** | 在折 A 上检测事件/构造特征，在**互斥**的折 B 上测结果。避免同一条评论同时贡献"因"和"果"造成的机械膨胀。 |
| **置换安慰剂（placebo）** | 把标签随机打乱后跑**完全相同**的流程，得到"纯靠噪声和极值选择能产生多大的假差距"。 |
| **比值（ratio）** | 观测差距 ÷ 安慰剂差距。< 1.5 判"无判别力"。 |
| **前趋势（pre-trend）** | 事件发生**之前**处理组与控制组的走势差，应 ≈ 0。不为 0 说明两组本来就不同，差异不是事件造成的。 |
| **MDE** | 最小可检测效应。当前样本能可靠检出的最小差异；比它更小的效应不是"不存在"，是"看不见"。 |
| **Direct Method** | 直接对结果建模（结果回归），不需要倾向性得分。无随机化日志时的唯一合规路径（IPS/SNIPS 被本项目规则禁止）。 |
| **IPS/SNIPS** | 用记录策略的概率做加权的离线评估方法。需要**记录策略**，本项目没有，且规则明令禁止包装。 |
| **AMBER_ASSOCIATIONAL** | 结论强度标记：只有关联性证据，**不得升级为因果**。 |
| **AMBER_NO_DISCRIMINATION** | 评估方法本身**无法区分好策略与坏策略**，因此任何"策略 A 更好"的说法都无效。 |
