## 结论先行

1. **测量工具修好了**。项目自己预注册的规则 `crossfit.rule = "detect_on_one_fold_measure_outcome_on_the_other"` 此前从未被执行——Wave5 用池化 `smoothed_net` 测量结果，而事件正是按折检测的，等于用尺子量自己。同折对照显示这个偏差高达交叉折的 **4.5–11 倍**，且在滞后·水平规格下**符号翻转**。
2. **下游效应确实存在，但是"同步"而非"领先"**。用**折外其他客人的评分**做结果变量：检测到方面改善的酒店，当季其他客人评分相对匹配对照 **+0.114 分（p=0.0019）**，平行趋势干净（k=−2: −0.022, p=0.55）。连续处理规格独立印证 **+0.101（p=3e-7）**。
3. **不能说"改善方面 X 会提升下季度评分"**。领先规格（方面变化 → 下季度评分变化）β=−0.034（p=0.13），与 0 不可区分；事件研究 k=1、k=2 为正但不显著。**这是负结果，必须保留。**
4. **仍然不是收益**。数据无房价、间夜、成本字段，`no_roi`、`no_demand_lift` 维持 True。现在有的是"评分"这一环，收益折算（P5）仍需外部价格弹性假设。

## P2b 交叉折连续处理效应（已完成）

产物：`outputs/autonomous/p2/effect_estimates.json` / `EFFECT_ESTIMATES.md`

规格：单元 = 酒店×方面×季度（仅完整季度）；处理 = 检测折 F 的方面情感；结果 = **另一折 G** 的评分；双向固定效应（酒店×方面吸收 + 时期哑变量）；按酒店聚类的稳健标准误；两个方向 A→B、B→A 分别估计后取均值。

| 时序 | 交叉折 β | 同折（机械耦合） | location 阴性对照 |
|---|---|---|---|
| 滞后·差分 x=Δsn_F(t)→Δms_G(t+1) | −0.034 (p=0.13) | −0.377 (p=3e-51) | −0.010 (p=0.84) ✓ |
| 同期·差分 x=Δsn_F(t)→Δms_G(t) | **+0.101 (p=3.1e-7)** | +0.755 (p=1e-160) | +0.043 (p=0.36) ✓ |
| 滞后·水平 x=sn_F(t)→ms_G(t+1) | **+0.057 (p=0.0025)** | −0.072（**符号翻转**） | +0.038 (p=0.37) ✓ |
| 同期·水平 x=sn_F(t)→ms_G(t) | **+0.187 (p=7.5e-27)** | +0.834 (p=4e-237) | +0.080 (p=0.046) ⚠ |

**三个要点：**

- **同折 vs 交叉折**相差 4.5–11 倍，滞后·水平甚至符号翻转。这直接量化了 Wave5 的自指偏差有多大——不是"偏大一点"，是**结论方向都可能反**。
- **置换检验**：200 次置换 β 分布 sd=0.0247，与解析 se=0.0224 吻合，标准误标定正确（置换 p=0.06 vs 解析 p=0.13）。
- **分方面**（同期·差分）：service **+0.191 (p=7.5e-6)** 最强，room +0.097 (p=0.025)、value +0.090 (p=0.016) 次之，breakfast +0.060 (p=0.099) 最弱。**service 是明确的最高杠杆**——这条可直接喂给 P3 的推荐排序。

## P2c 匹配 DiD 稳健性对照（已完成）

形态差异很关键：自指臂效应**持续不衰减**；折外评分臂在事件期冲高后 k=1、k=2 衰减且不显著。这与 P2b 的"同步强、领先弱"完全一致——**两个独立设计互相印证**。

## 量级换算

- 一次典型检测事件 Δnet ≈ 0.384 → 连续规格推算 **+0.039 分**；匹配 DiD 实测 **+0.114 分**（0–10 分制，样本均分 8.45、sd 0.79）。
- 即约 **0.5%–1.4% 的相对评分提升**。量级很小，且是同步的。

## 必须记住的局限

1. **不是因果**。折分离消除了同评论机械耦合，但没有随机化；酒店质量冲击会同时推动方面口碑与其他客人评分。
2. **领先效应是负结果**，"改善方面 → 下季度变好"没有证据支持。若要对外讲收益，这是硬约束。
3. **location 阴性对照在同期·水平下 p=0.046 边际显著**。location 作为"不可变"对照其实偏弱：客人对位置的评价会随整体满意度波动，它并不是一个干净的阴性对照。其余三个时序均不显著。
4. **测量误差导致衰减**：处理变量含与结果无关的抽样误差（经典 EIV），|β| 被压向 0，所有估计是**量级下界**。
5. **收益链条断在最后一环**：没有价格、间夜、成本，评分→收益仍要靠外部弹性假设折算。

## 对 P3（算法优化）的含义

- 现在有了**可用的优化靶标**：折外其他客人评分的同期响应。P3 可以把"设计选择权重"改为在这条已验证链路上做选择/学习，并以超过 P2 基线为验收标准。
- service 是最强杠杆，权重若可调，应向 service 倾斜；breakfast 最弱。
- **必须先做 P4（离线策略评估）**：在报告增益前，需要 IPS/SNIPS 之类的反事实评估，否则权重调优只是在同一批数据上刷分。
