## Q3 Does using it beat a scrambled value vector?

**Read this section with care.** The reward here is the value of the picked aspect under an independently estimated v -- i.e. the reward is DEFINED BY the same quantity the policy optimises. `value_aware` beating `peer_relative` and `random_uniform` is therefore close to tautological and proves nothing about outcomes. The only non-circular entry in the table is `placebo_permuted_v` (identical weights, scrambled across aspects): it isolates whether the ALIGNMENT between weight and aspect matters, which is the one thing the policy actually contributes. The honest outcome evidence is Q3b and the P4 re-run below.

## Q3b Out-of-hotel prediction from ONLY the picked aspect

The one test that touches the observed outcome: fit `y = a + b * level(picked aspect)` on train hotels, score R^2 on held-out hotels.

`random_uniform` is a reference, not a floor: its predictor is a mixture over all six actionable aspects, so it inherits the AVERAGE per-aspect slope, whereas `largest_deficit` always selects the extreme-low aspect and so is dominated by measurement noise. A reference beating the shipped policy's pick is not evidence for anything. The fair floor is `placebo_permuted_v`: the same weights, scrambled across aspects.

## Verdict

- value vector: **REAL_AND_STABLE**
- policy gain (fold-out reward proxy): **GAIN_BEATS_PLACEBO**
- outcome probe (does the vector's ALIGNMENT help on real ratings): **CONDITIONAL_BEATS_SCRAMBLED** (conditional 0.0762, scrambled 0.0580, marginal 0.0345; oracle ceiling 0.334)
- specification: Both specifications beat a scrambled-v placebo, but only the CONDITIONAL vector also clears the random-aspect reference on the observed outcome. The marginal vector is nearly flat, so it barely changes which aspect gets picked and inherits the weak largest-deficit behaviour. Ship conditional.
- note: Cross-sectional level association. NOT a causal or revenue claim; the forward reward in P4 cannot distinguish policies.
